# Задача 6. Квартальный рейтинг станций

**Тип задачи:** сводная из нескольких файлов. **Отдел:** организационно-административный.

Каждый квартал отдел собирает рейтинг станций по отчётам, которые прислали сами станции. Отчёты приходят в разном виде, а методика рейтинга одна.

**Файлы:** папка `reiting/` (отчёты станций за 3 квартал) и методика `reiting_metodika.md`.

## Что нужно получить

1. Таблицу: станция, пять показателей, балл по методике, место.
2. Список того, что пришлось поправить или нельзя посчитать, и почему.
3. Три предложения для руководителя: кто лучший, кто худший, на что обратить внимание.

Таблицу сохраните в Excel.

## Готово, когда

- В рейтинге 12 станций, каждая один раз.
- Все показатели приведены к одним единицам.
- Пропуски названы, расчёт с ними сделан по методике.
- Балл любой станции можно пересчитать руками по методике.

## Если работаете в чате

Загрузите в разговор все файлы из папки `reiting/` и методику. Попросите сначала описать, как устроен каждый файл, и только потом считать.
