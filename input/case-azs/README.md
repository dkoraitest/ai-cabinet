# Учебный кейс «Дала Ойл»

Это учебные данные одной рабочей недели условной сети АЗС. Сеть, компании и люди выдуманы. Данные устроены так же, как настоящие выгрузки: в них есть пропуски, повторы и противоречия. Хороший промпт заставит Claude сказать «нет данных» или «здесь противоречие». Плохой получит уверенную выдумку.

## Легенда

Сеть «Дала Ойл»: 12 АЗС в трёх городах. В Астане АЗС-01 - АЗС-05, в Караганде АЗС-06 - АЗС-09, в Павлодаре АЗС-10 - АЗС-12. Продают АИ-92, АИ-95, дизельное топливо и газ (на АЗС-12 газа нет). При станциях минимаркеты и кафе.

Сегодня понедельник, 21 сентября 2026 года. Вы недавно пришли в центральный офис, и отделы принесли по задаче. У задачи 7 свои даты, они указаны в ней.

| Отдел | Задача | Тип задачи | Файлы |
|---|---|---|---|
| Коммерческий отдел | Сводка продаж за прошлую неделю для руководителя | Сводная | `sales_azs_1c.csv`, со звёздочкой `sales_azs_1c_year.csv` |
| Бухгалтерия | Сверить акт от поставщика топлива с нашим учётом за август | Сверка | `supply_akt_sverki.xlsx`, `supply_nash_uchet.xlsx` |
| Отдел закупок | Письмо поставщику о расхождениях по акту сверки | Черновик по шаблону | `template_pismo_postavshchiku.docx` (или `.md`) и итог сверки |
| Служба клиентского сервиса | Разобрать обращения клиентов за неделю по темам | Классификация | `obrashcheniya.xlsx` |
| Административный отдел | Какие договоры скоро заканчиваются и что продлевать | Реестр со сроками | `reestr_dogovorov.xlsx` |
| Организационно-административный | Квартальный рейтинг станций по их отчётам | Сводная из нескольких файлов | папка `reiting/`, `reiting_metodika.md` |
| Организационно-административный | Реестр поручений селектора в рабочих днях (свои даты: протокол 12.10, сегодня 02.11) | Реестр со сроками | `porucheniya_*`, `kalendar_oktyabr_noyabr_2026.xlsx` |
| Организационно-административный | Объявление на казахском по глоссарию | Черновик по шаблону | `perevod_obyavlenie_ru.docx`, `perevod_glossariy.xlsx` |
| Закупки и юридический отдел | Договор поставщика против типовой формы | Сверка по шаблону | `dogovor_tipovaya_forma.docx`, `dogovor_postavshchika.docx` (или `.md`) |

Каждая задача описана отдельно в папке `tasks`: что нужно получить и как понять, что готово.

На первых двух воркшопах файлы кейса загружаются в чат или в Проект Claude, архив кейса лежит на странице воркшопа на платформе курса. В рабочем кабинете те же файлы лежат в папке `input/case-azs/`.

## Что в файлах

| Файл | Что это |
|---|---|
| `sales_azs_1c.csv` | Выгрузка продаж из 1С за две недели, 7-20 сентября: по дням, сменам, станциям и видам топлива |
| `sales_azs_1c_year.csv` | Та же выгрузка за год, около 100 тысяч строк. Только для задания со звёздочкой в кабинете, в архив для чата не входит |
| `supply_akt_sverki.xlsx` | Акт сверки за август, который прислал поставщик «НефтеСнаб Сарыарка» |
| `supply_nash_uchet.xlsx` | Наш учёт поставок и оплат этому поставщику |
| `template_pismo_postavshchiku.docx` | Шаблон письма поставщику о расхождениях. То же в `.md` |
| `obrashcheniya.xlsx` | 80 обращений клиентов за 14-20 сентября: WhatsApp, колл-центр, отзывы, книга жалоб |
| `reestr_dogovorov.xlsx` | Реестр договоров по трём городам и лист «Справочник» |
| `sales_azs_1c_week3.csv` | Выгрузка продаж за следующую неделю, 21-27 сентября: новая выгрузка для повторного запуска |
| `reiting/` | Квартальные отчёты станций за 3 квартал, каждая станция прислала свой файл |
| `reiting_metodika.md` | Методика квартального рейтинга станций |
| `porucheniya_protokol.docx` | Протокол селекторного совещания с поручениями. То же в `.md` |
| `porucheniya_ispolnenie.xlsx` | Отметки об исполнении поручений |
| `kalendar_oktyabr_noyabr_2026.xlsx` | Нерабочие дни октября и ноября 2026 года |
| `perevod_obyavlenie_ru.docx` | Объявление для станций на русском. То же в `.md` |
| `perevod_glossariy.xlsx` | Глоссарий русских и казахских терминов компании |
| `dogovor_tipovaya_forma.docx` | Типовая форма договора поставки нефтепродуктов «Дала Ойл». То же в `.md` |
| `dogovor_postavshchika.docx` | Договор поставки, который прислал поставщик на согласование. То же в `.md` |

## На что обратить внимание

Сначала смотрите на сами данные, потом на выводы. Если Claude назвал цифру, спросите, из какой строки файла она взялась. Если в данных чего-то нет, правильный ответ «нет данных». Правдоподобная догадка здесь считается ошибкой.

Нашли место, где данные расходятся или чего-то не хватает: отметьте. Это тема разбора на занятии.
