# Методика квартального рейтинга АЗС

Рейтинг считается по пяти показателям из квартальных отчётов станций.

| Показатель | Вес | Что лучше |
|---|---|---|
| Выполнение плана продаж, % | 30% | больше |
| Тайный покупатель, баллы из 100 | 25% | больше |
| Нарушения стандартов, шт | 15% | меньше |
| Жалобы на 1000 чеков | 20% | меньше |
| Текучесть персонала, % | 10% | меньше |

Как считать:

1. По каждому показателю станции получают балл от 0 до 100: лучшее значение среди станций 100, худшее 0, остальные пропорционально.
2. Итоговый балл станции: сумма баллов по показателям, умноженных на веса.
3. Если показателя у станции нет, его вес делится между остальными показателями этой станции пропорционально их весам. В рейтинге рядом со станцией ставится пометка.
4. Если у станции несколько версий отчёта, берётся последняя версия.
5. При равенстве баллов выше та станция, у которой выше выполнение плана.
