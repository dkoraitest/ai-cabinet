# Добавить в кабинет

Сервис сделан в своей папке-проекте. Этот скилл показывает его в кабинете: карточка на странице «мой кабинет» в разделе «Мои сервисы» с кнопкой «Запустить». Кабинет запускает программу прямо из папки проекта, сам проект остаётся на месте.

Человек не разработчик: говори просто, без слов команда, терминал, скрипт, Git. Сырой вывод не показывай, пересказывай.

## 1. Папка проекта и кабинет

Папку проекта дальше зову `<проект>`, папку кабинета `ai-cabinet` зову `<кабинет>`. Пути в командах всегда в кавычках и без косой черты в конце: в них бывают кириллица и пробелы.

Проект: папка этого разговора, если в ней есть `main.py` или `service.json`. Разговор открыт в самом кабинете (в его папке лежат `START.md` и `tools/services.mjs`): спроси, какую папку сервиса добавить (уже добавленные покажет `node tools/services.mjs list`). Иначе спроси путь к папке сервиса.

Кабинет:

- Разговор в кабинете: команды пиши от его папки, `node tools/services.mjs ...`, окон разрешения не будет.
- Иначе бери папку, из которой поставлен этот скилл: `{{KABINET}}`. Видишь вместо пути слово в двойных фигурных скобках: скилл поставлен не кабинетом, переходи к следующему пункту.
- Команда кабинета ответила `Cannot find module` (файла нет) или пути выше нет: найди кабинет одной командой. Она смотрит переменную среды `AI_CABINET_DIR`, затем `Documents/ai-cabinet` и `Документы/ai-cabinet` в домашней папке (и в OneDrive) и печатает путь или «нет»:

  ```
  node -e "const f=require('fs'),p=require('path'),h=require('os').homedir();const c=[process.env.AI_CABINET_DIR,p.join(h,'Documents','ai-cabinet'),p.join(h,'Документы','ai-cabinet'),p.join(h,'OneDrive','Documents','ai-cabinet'),p.join(h,'OneDrive','Документы','ai-cabinet')].filter(Boolean);console.log(c.find(x=>f.existsSync(p.join(x,'tools','services.mjs')))||'нет')"
  ```

- Ответ «нет»: спроси «Где лежит папка вашего кабинета ai-cabinet? Откройте её в Проводнике, щёлкните по адресной строке вверху, скопируйте путь и вставьте сюда.»

## 2. Паспорт service.json

Прочитай `<проект>/service.json` инструментом чтения файлов.

- Файла нет: собери его по образцу ниже из того, что знаешь о сервисе (правила проекта, программа, этот разговор). Покажи человеку название и описание одной строкой и спроси «Так?». Записывай после ответа.
- Файл есть: проверь поля. `name`: название сервиса, не заглушка «Новый сервис». `about`: что делает сервис одной фразой, не заглушка. `kind`: `run` или `page`. `run`: файл `.py`, который есть в проекте. `result`: `output/result.json`. У `kind` `page`: папка из поля `page` есть в проекте. `api` (если есть, действия своей страницы): файл `.py` в проекте, обычно `api.py`, его код проверяется так же, как программа. Чего не хватает, допиши так же: покажи и спроси «Так?».

Образец:

```json
{
  "name": "Сводка продаж по АЗС",
  "about": "Каждый понедельник литры по АЗС из выгрузки 1С, падение больше 20% красным",
  "kind": "run",
  "run": "main.py",
  "result": "output/result.json",
  "input": "input/",
  "page": null
}
```

## 3. Программа проверена?

В этом разговоре программа не запускалась или не сверялась с известным ответом: сначала сделай это по правилам проекта (запуск `python main.py`, на Mac `python3 main.py`, сверка с числом человека). Без сверки дальше не иди: скажи, что сначала проверишь программу на известном ответе. Правил проекта нет (папка сделана не из шаблона): спроси у человека одно число, которое он знает точно, и сверь с ним `output/result.json`.

## 4. Окна разрешения

Разговор не в кабинете: настройки кабинета здесь не действуют, и Claude Code спросит разрешение на каждое действие кабинета. Скажи заранее одной фразой: «Сейчас Claude три раза попросит разрешение на действия кабинета: проверить программу, пробно запустить её и записать сервис в кабинет. Нажмите **Allow** (разрешить) в каждом окне.»

## 5. Проверка, пробный запуск, запись

По очереди, каждое следующее только после успеха предыдущего:

1. `node "<кабинет>/tools/services.mjs" check "<проект>"`: та же проверка, что у программ процессов кабинета (запуск других программ, eval и exec, прямые обращения к моделям, пути вне проекта, библиотеки не из списка). Нашлось: исправь программу по причинам из вывода, не обходя проверку, запусти её, снова сверь с известным ответом и повтори проверку. Причина в папке `lib`: её не трогай, позови тренера.
2. `node "<кабинет>/tools/services.mjs" run "<проект>"`: пробный запуск, как кнопкой «Запустить». Ответ «Готово: ...» с итогом: дальше. «Расчёт ... не удался»: причина в последних строках журнала в выводе. Понятная причина (например, нет файла в `input`): перескажи и попроси человека её убрать, потом повтори. Файл результата открыт в Excel или Word: попроси закрыть и повтори. «Сбой программы сервиса» или результат не годится для карточки: исправь программу, запусти `python main.py`, сверь и повтори шаги 1 и 2. «Уже идёт»: подожди минуту и повтори.
3. `node "<кабинет>/tools/services.mjs" add "<проект>"`: записывает сервис в кабинет. Сервис уже был в кабинете: запись обновится, это нормально.

Что ещё бывает:

- `Cannot find module`: кабинет не там, вернись к разделу 1.
- Node не найден: «На компьютере нет программы Node.js, без неё кабинет не работает. Позовите тренера.»
- Человек не разрешил действие: скажи, что без него сервис в кабинет не попадёт, и спроси, повторить ли.
- Другая ошибка по-русски: перескажи своими словами и предложи позвать тренера. Сам файлы кабинета (`me/servisy.json` и другие) не правь.

## 6. Что сказать человеку

«Готово: сервис «<название>» в кабинете. На странице «мой кабинет» в разделе «Мои сервисы» его карточка с кнопкой «Запустить». Страница уже открыта: обновите её (F5). Не открыта: в разговоре в папке кабинета скажите «открой страницу» или дважды щёлкните start-cabinet.cmd в папке кабинета.
Доработаете сервис здесь: снова скажите «добавь в кабинет», я проверю программу ещё раз.»

У сервиса со своей страницей (`kind` `page`) вместо «карточка с кнопкой «Запустить»» скажи: «его карточка с кнопкой «Открыть»: своя страница сервиса откроется внутри кабинета такой, как мы её сделали, кнопка «Запустить» над ней». Правки только страницы (`page/`) добавлять заново не нужно: хватит обновить страницу кабинета (F5).
