# Новый сервис

Сервис участника живёт в своей папке-проекте: там человек с Claude делает программу, а кабинет потом показывает и запускает её («добавь в кабинет»). Этот скилл создаёт такую папку из шаблона кабинета. Сам сервис здесь не пиши: правила проекта действуют только в разговоре, открытом в его папке.

Человек не разработчик: говори просто, без слов команда, терминал, скрипт, Git. Сырой вывод не показывай, пересказывай.

## 1. Где кабинет

Папку кабинета `ai-cabinet` дальше зову `<кабинет>`. Пути в командах всегда в кавычках и без косой черты в конце: в них бывают кириллица и пробелы.

- Разговор открыт в самом кабинете (в его папке лежат `START.md` и `tools/services.mjs`): команды пиши от неё, `node tools/services.mjs ...`, окна разрешения не будет.
- Иначе бери папку, из которой поставлен этот скилл: `{{KABINET}}`. Видишь вместо пути слово в двойных фигурных скобках: скилл поставлен не кабинетом, переходи к следующему пункту.
- Команда кабинета ответила `Cannot find module` (файла нет) или пути выше нет: найди кабинет одной командой. Она смотрит переменную среды `AI_CABINET_DIR`, затем `Documents/ai-cabinet` и `Документы/ai-cabinet` в домашней папке (и в OneDrive) и печатает путь или «нет»:

  ```
  node -e "const f=require('fs'),p=require('path'),h=require('os').homedir();const c=[process.env.AI_CABINET_DIR,p.join(h,'Documents','ai-cabinet'),p.join(h,'Документы','ai-cabinet'),p.join(h,'OneDrive','Documents','ai-cabinet'),p.join(h,'OneDrive','Документы','ai-cabinet')].filter(Boolean);console.log(c.find(x=>f.existsSync(p.join(x,'tools','services.mjs')))||'нет')"
  ```

- Ответ «нет»: спроси «Где лежит папка вашего кабинета ai-cabinet? Откройте её в Проводнике, щёлкните по адресной строке вверху, скопируйте путь и вставьте сюда.»

## 2. Название

Человек уже назвал сервис («создай сервис сводка продаж по АЗС»): бери это название. Иначе спроси обычным текстом: «Как назовём сервис? Например: «Сводка продаж по АЗС».» Название по-русски, как скажет человек; имя папки латиницей кабинет сделает сам.

## 3. Создать папку

Разговор открыт не в кабинете: настройки кабинета здесь не действуют, и Claude Code спросит разрешение на команду кабинета. Перед ней скажи одной фразой: «Сейчас Claude попросит разрешение выполнить действие кабинета: оно создаст папку сервиса. Нажмите **Allow** (разрешить).»

Запусти:

    node "<кабинет>/tools/services.mjs" new "<название>"

Команда создаёт папку проекта в папке `Сервисы` рядом с кабинетом (обычно `Документы/Сервисы/<папка латиницей>`) из шаблона кабинета, кладёт в неё помощников кабинета и заводит историю версий (git). Папка с таким именем уже есть: команда сама возьмёт имя с `-2`, `-3`. Путь к новой папке возьми из строки «Сервис «...» создан: <путь>».

Что бывает:

- Готово: идёшь к разделу 4. В выводе сказано, что git не найден или не включился: ничего не чини, сервис работает и так; скажи об этом человеку одной фразой.
- Человек хочет держать сервисы в другой папке: добавь в конец команды `--dir "<папка>"`.
- `Cannot find module`: кабинет не там, вернись к разделу 1.
- Node не найден: «На компьютере нет программы Node.js, без неё кабинет не работает. Позовите тренера.»
- Другая ошибка по-русски: перескажи её своими словами и предложи позвать тренера. Сам папку не создавай и шаблон не копируй.
- Человек не разрешил действие: скажи, что без него папку не создать, и спроси, повторить ли.

## 4. Что сказать человеку

«Готово: папка сервиса <путь>.
1. Положите файлы с данными в её папку input (через Проводник).
2. Откройте эту папку в новом разговоре: в приложении Claude **Code** (вкладка Code) → **Local** (на этом компьютере) → **Open folder…** (открыть папку), в VS Code **File** (файл) → **Open Folder…** (открыть папку). Claude спросит, доверяете ли вы этой папке: **Yes** (да).
3. Там опишите, что должен делать сервис: из каких файлов, что посчитать, что показать в итоге. И назовите одно число, которое вы знаете точно: Claude проверит на нём программу.
Когда сервис будет готов, там же напишите «добавь в кабинет».»
