# Проект сервиса

Это папка вашего сервиса. Сервис: программа, которая сама делает одну вашу регулярную задачу, например каждую неделю сводит продажи по АЗС. Claude помогает её сделать, а работает она без Claude: по кнопке «Запустить» на странице «мой кабинет».

## Как работать

1. Откройте эту папку в новом разговоре. В приложении Claude: **Code** (вкладка Code) → **Local** (на этом компьютере) → **Open folder…** (открыть папку). В VS Code: **File** (файл) → **Open Folder…** (открыть папку), затем панель Claude. Claude спросит, доверяете ли вы этой папке: ответьте **Yes** (да, доверяю), иначе правила проекта не заработают.
2. Положите файлы с данными в папку `input` этой папки, через Проводник. Файлы с персональными данными людей сначала обезличьте.
3. Опишите Claude, что должен делать сервис: из каких файлов, что посчитать, что показать в итоге и как часто. Назовите одно число, которое вы знаете точно, например итог за прошлую неделю: Claude проверит на нём программу.
4. Claude напишет программу, запустит её и сверит с вашим числом.
5. Когда всё сходится, напишите **добавь в кабинет**. Сервис появится на странице «мой кабинет» с кнопкой «Запустить». Claude попросит разрешение на действия кабинета и заранее скажет, где нажать **Allow** (разрешить).

Доработать сервис: откройте эту папку в новом разговоре и скажите, что поменять. После доработки снова напишите **добавь в кабинет**: Claude проверит программу ещё раз.

## Что где лежит

- `input`: ваши файлы с данными. Claude их не меняет.
- `output`: результаты сервиса.
- `main.py`: программа сервиса.
- `service.json`: паспорт сервиса: название и что он делает.
- `CLAUDE.md`: правила проекта для Claude. Внизу раздел «Уроки»: Claude записывает туда выводы после ошибок.
- `lib`: помощники из кабинета. Не меняйте.
- `.env`: ключи для сайтов, если они нужны сервису. Этот файл создаёте вы сами, Claude его не читает.

## Ключи и пароли

Не вставляйте их в чат. Если сервису нужен ключ сайта, создайте в этой папке в Блокноте файл `.env` («Сохранить как», тип «Все файлы») и запишите в него строку `ИМЯ=значение`. Имя подскажет Claude.

## Если застряли

Напишите Claude «помоги разобраться» и опишите, что видите на экране. Не помогло: позовите тренера.
