# Кабинет участника AI Camp

Рабочая папка участника курса по Claude: правила для Claude, скиллы курса, учебный кейс и страница «Мой кабинет». Как работать в кабинете, написано в [START.md](START.md).

## Как поставить кабинет

1. Откройте вкладку **Code** в приложении Claude → **Local** (на этом компьютере) → **Open folder…** (открыть папку) и выберите папку **Documents** (Документы). В VS Code: **File** (файл) → **Open Folder…** (открыть папку), затем панель Claude.
2. Вставьте Claude ссылку на эту страницу и напишите «поставь кабинет». Claude попросит разрешение скачать кабинет: нажмите **Allow** (разрешить).
3. Claude скачает кабинет в папку `ai-cabinet` и попросит открыть её в новом разговоре. Откройте папку `ai-cabinet` так же, как в шаге 1, и напишите «начнём».

Новый разговор нужен обязательно: правила и настройки кабинета действуют только в разговоре, открытом в папке `ai-cabinet`.

## Для Claude

Человек прислал ссылку на этот репозиторий, чтобы поставить кабинет. Он не разработчик: говори без технических слов (папка, а не директория; скачать, а не клонировать). Сделай так:

1. Если разговор уже открыт в папке кабинета (в ней лежат `CLAUDE.md` и `START.md` этого репозитория), кабинет стоит: работай по `CLAUDE.md`, ничего не скачивай.
2. Если в папке разговора уже есть папка `ai-cabinet` с `CLAUDE.md`, заново не скачивай: переходи к шагу 4.
3. Скачай кабинет одной командой из папки разговора: `git clone https://github.com/dkoraitest/ai-cabinet.git ai-cabinet`. Не получилось (нет git, нет связи с GitHub, ошибка сертификата): скажи простыми словами, что помешало, приведи текст ошибки отдельной строкой для тренера или ИТ и предложи позвать тренера. Архив вместо этого не скачивай: кабинет из архива не обновляется.
4. Больше в этом разговоре ничего не запускай: ни проверку сетапа, ни страницу, ни установку библиотек. Настройки кабинета (защита файлов процессов, разрешения, модель) Claude берёт при начале разговора из его папки, поэтому здесь они не действуют.
5. Скажи человеку: «Кабинет готов: папка ai-cabinet в <папка разговора>. Откройте её в новом разговоре: в приложении Claude **Code** (вкладка Code) → **Local** (на этом компьютере) → **Open folder…** (открыть папку), в VS Code **File** (файл) → **Open Folder…** (открыть папку). Там напишите «начнём».»
