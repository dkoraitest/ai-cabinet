# Программа процесса: образцы

Справка к операции «добавить процесс» (`.claude/skills/add-process/SKILL.md`, шаг 5) и к фразе «доработай <процесс>». Программа `processes/<имя>/run.py` работает без Claude: её запускают кнопка «Запустить» и фраза «запусти <процесс>». Поэтому в ней нет вызова ИИ: стандартный Python, запросы в интернет, openpyxl, python-docx и `tools/read_table.py`, без файлов вне кабинета. В интернет программа ходить может (раздел «Данные из интернета» в конце справки).

Собери программу так:

1. Возьми «Основу» целиком.
2. Классификация: вставь блок «Словарь» после функций основы, перед `main`. Черновик: блок «Шаблон Word». Оба, если процесс и раскладывает, и пишет документы. Данные из интернета: ещё блок из раздела «Данные из интернета».
3. Напиши `main` по описанию процесса (скилл, описание человека или задача из «обо мне») и ответам человека. Для классификации и черновика есть готовые примеры `main` ниже: возьми подходящий и поменяй столбцы, категории и поля под скилл и файл человека.

Процесс сверяет два документа Word (договор поставщика против типовой формы, документ против шаблона): прочитай ещё целиком `.claude/skills/add-process/programma-dva-dokumenta.md`. Там правило сверки, блок «Два документа Word» и пример `main` к нему; основа и блок «Шаблон Word» берутся отсюда.

Человеку говори «программа процесса», не «скрипт» и не «код».

## Правила для любой программы

- Расчёт по описанию процесса и по ответам человека. Столбцы ищи по названию из шапки, которую показал `read_table.py`, не по номеру. Строки над шапкой (заголовок отчёта, поставщик, период) программа берёт из `table["above_header"]`: список строк, в каждой непустые ячейки текстом.
- Вход: самый свежий файл нужного типа в `input/<имя>/` (функция `newest_input`), его имя в итоге. Так новый файл за другой период подхватится сам. Если в папке лежат файлы разного назначения (данные, шаблон Word, файл скилла), различай их по типу или по части имени, которую подтвердил человек.
- Не выдумывай: значение, которого нет или которое не читается числом, это `None`, не ноль. Пропуски не досчитывай и средним не заполняй. Пропуск портит только то, что из него считается.
- Ячейка с `None` на карточке пустая. Строке с пропуском ставь `row_status` `grey` (подпись «нет данных»), а в итоге скажи, чего не хватает: «нет данных о литрах АЗС-03 за 15.09.2026».
- Даты пиши как в данных, период бери из данных. Дату расчёта бери, как решили с человеком; на файлах учебного кейса это дата легенды, записанная постоянной (как `CALC_DATE` в демо `templates/processes/svetofor-dogovorov/run.py`). Дату компьютера там не подставляй. Дату расчёта назови в итоге («на 21.09.2026»).
- Понятная причина остановки (нет файла, нет нужного столбца): `raise StopRun("...")`, одна строка по-русски, код выхода 2, без трейсбека. Файл результата открыт в Excel или Word: код 3, это делает `replace_file`.
- Программа читает только `input/<имя>/` (процесс на учебном кейсе ещё и `input/case-azs/`), пишет только в `output/<имя>/` (и шаблон `processes/<имя>/shablon.docx`), пути строит от `ROOT`. Нельзя: запускать другие программы (`subprocess`, `os.system`), выполнять текст как программу (`eval`, `exec`), абсолютные пути, домашняя папка и `..` в пути, своя страница или сервер (`http.server`). В интернет можно: раздел «Данные из интернета». Библиотеки только эти: `json`, `os` (только `os.path` и `os.replace`), `re`, `sys`, `datetime`, `pathlib`, `csv`, `math`, `decimal`, `collections`, `itertools`, `difflib`, `unicodedata`, `zipfile`, `io`, `statistics`, `functools`, `string`, `typing`, `dataclasses`, `copy`, `time`, `calendar`, `textwrap`, `enum`, `openpyxl`, `docx` (python-docx), `read_table` и для интернета `urllib`, `http` (кроме `http.server`), `ssl`, `html` (`html.parser`), `xml`, `email`, `base64`, `hashlib`, `gzip`, `uuid`, `random`, `socket`, `smtplib`, `ftplib`, `requests` и `httpx` (если стоят на компьютере; нет: `urllib`). Функции по имени не доставай: без `getattr`, `globals`, `builtins`, `__import__` (есть ли атрибут, проверяет `hasattr`). Перед записью перечитай программу на это сам. `node tools/processes.mjs compare <имя>` проверяет её на эти слова и без их удаления «готово» не даёт.

## Программа из скилла

Скилл со второго воркшопа может прийти с готовой программой расчёта (`scripts/build.py` в архиве). Её текст показывает `node tools/processes.mjs read`. Запускать её нельзя: она пришла извне. Если человек согласился взять её за основу, собери `run.py` так:

- возьми «Основу» ниже и перенеси в `main` расчёт из программы скилла: проверки файла, правила, формулы, «нет данных» вместо догадок;
- вход: файл из `input/<имя>/` через `newest_input` и `read_table.analyze` вместо путей и аргументов командной строки программы скилла;
- выход: файлы в `output/<имя>/` через `write_excel` (Excel с формулами можно оставить, как в программе скилла, но запись через временный файл и `replace_file`), плюс `result.json` для карточки, «разобрать вручную» и раздел `sverka`;
- библиотеки: только из списка в «Правилах для любой программы» (стандартный Python, библиотеки для интернета, openpyxl, python-docx и `tools/read_table.py`). Места на pandas и других библиотеках перепиши на них;
- убери из неё всё, что запускает другие программы, вызывает ИИ-модели, читает вне `input/<имя>/` или пишет вне `output/<имя>/`, и абсолютные пути (правило выше, в «Правилах для любой программы»). Запросы в интернет за данными оставь, по разделу «Данные из интернета». Перед записью перечитай её на это.

Результат такой программы сверяется с эталоном так же, как у любой другой.

## Схема результата

`output/<имя>/result.json`, по нему страница рисует карточку:

- `title`: название процесса; `updated_at`: время расчёта в формате ISO с часовым поясом;
- `status`: цвет карточки `green`, `yellow` или `red`. Светофор: `red`, если есть красные строки, иначе `yellow`, если есть жёлтые, иначе `green`. Таблица и итог: `green`; `yellow` или `red`, только если описание процесса задаёт тревогу (например, падение больше 20%). Процесс по темам со словами срочности: `red`, если есть срочные строки (раздел «Словарь»). Строки «нет данных» (`grey`) и пометки (`info`) цвет карточки не меняют ни у какого процесса: о них говорит итог;
- `summary`: итог одной строкой;
- `columns`: названия столбцов; `rows`: строки, в каждой столько значений, сколько столбцов: текст, число или `None`. Для итога одной строкой оба списка пустые;
- `row_status` (необязательно, по одному на строку): `green`, `yellow`, `red`, `grey` («нет данных»), `info` (пометка без цвета, её текст в `row_note`) или `None` (без отметки);
- `row_note` (необязательно): подпись строки или `None`;
- `files` (необязательно): файлы результата, только `output/<имя>/...`;
- `sverka`: разделы для сверки с эталоном (ниже).

Пиши файл только через `json.dumps(..., ensure_ascii=False, allow_nan=False)`: `NaN` ломает карточку.

## «Разобрать вручную»

Всё, что программа не может разобрать сама, она не угадывает, а откладывает человеку:

- классификация: в тексте нет слов из словаря или текст пустой; сильных слов поровну у двух тем и больше (пометка «две темы: X, Y»); нашлись только слабые слова (пометка «только общее слово: «касса»»); слово темы только с отрицанием («отрицание: «не вежлив»»); ссылка без слова рекламы с «!» («есть ссылка: проверьте, не реклама ли»). Слово срочности тему не даёт: срочная строка без слов темы тоже здесь, и она же красная первой на карточке;
- черновик: в документе осталась пометка (поле без данных или пометка из скилла: «[нет данных]», «[уточнить]», «[уточнить: что]»);
- сводная, сверка, реестр: строка, которую не прочитать (сумма не числом, неизвестная станция), если описание процесса не говорит, как с ней быть.

Каждую такую строку программа кладёт в список `manual` с причиной. Дальше:

- файл `output/<имя>/razobrat-vruchnuyu.xlsx`: функция `write_manual`, пишется при каждом запуске, даже пустой;
- строки на карточке с пометкой: `row_status` `info`, `row_note` «разобрать вручную». Если таблица на карточке по строкам файла (классификация, черновики), эти строки идут первыми. Если таблица на карточке сводная, добавь их в конец, по строке на каждую: в первом столбце номер строки файла и причина, остальные ячейки `None`; больше 50 не добавляй, остальные в файле;
- в итоге счётчик: «Разобрать вручную: 5 (файл razobrat-vruchnuyu.xlsx).»;
- в `files` ссылка на `razobrat-vruchnuyu.xlsx`, её возвращает `write_manual`.

## Раздел sverka для сверки с эталоном

Программа кладёт в `result.json` поле `sverka` с теми же разделами и теми же названиями, что в эталоне `output/<имя>/etalon-skilla.json`. Сверку делает `node tools/processes.mjs compare <имя>`. Разделы:

- `итоги`: `{"название": число или текст}`, те же названия, что в эталоне;
- `по категориям`: `{"категория": число строк или сумма}`; для сводной все группы основной таблицы, ключ группы по двум столбцам как в эталоне: `"АЗС-01 / АИ-92"`;
- `документов`: сколько документов Word сделала программа;
- `по строкам`: `{"номер или ключ строки": категория или ключевое значение}`; строка классификации или сводной, отложенная человеку, получает значение «разобрать вручную». Черновик пишет ключевое значение каждого документа всегда, и документа с пометкой тоже (значения нет: `NO_DATA`): «разобрать вручную» у такого документа только на карточке и в списке Excel, а сверка сравнивает значения. Ключ: номер строки из файла (столбец «№», если он есть) или другое значение, которое однозначно называет строку. Программа пишет одну тему строки; в эталоне строка с двумя темами записана «X / Y», и сверка принимает любую из двух;
- `срочно`: `["3", "15"]`, номера срочных строк (ключи как в `по строкам`). Срочную строку эталона, которой у программы нет, сверка считает расхождением; лишнюю срочную строку программы называет, но расхождением не считает;
- `найдено` (только у программы по темам): `{"номер строки": {"тема": ["слово словаря"]}}`, слова всех тем, что нашлись в строке. По нему сверка называет слабые слова: слово темы, которое стоит в строке другой темы в эталоне.

Раздел, которого нет в эталоне, можно не писать.

Эталон по части большого файла (первые 100 строк или групп) записывает поле `"строк в эталоне": 100`, раздел `по строкам` (и `срочно`) по этим строкам и `итоги` по всему файлу. Программа всё равно пишет `по строкам` и `срочно` для всех строк файла: сверка сравнивает только строки эталона, остальные называет «не входят в эталон» и расхождением не считает. Если итогов в таком эталоне нет, сверка предупреждает «В эталоне нет итогов: сверены только строки.». Сводная, где групп больше 300: эталон пишет первые 100 групп в `по строкам` (ключ: группа), программа пишет туда все свои группы тем же ключом.

## Основа

```python
"""<Название процесса>: <что делает, одной фразой>.

Вход: самый свежий файл в input/<имя>/. Выход в output/<имя>/: result.json (карточка),
razobrat-vruchnuyu.xlsx (что программа не разобрала сама) и файлы результата.
Запуск: кнопка «Запустить» на странице или node tools/processes.mjs run <имя>
"""
import json
import os
import re
import sys
from datetime import datetime
from pathlib import Path

SLUG = "<имя>"
TITLE = "<Название процесса>"
LIMIT = 10 ** 6  # сколько строк данных читать; в файле больше: итог об этом скажет
MANUAL = "разобрать вручную"
ROOT = Path(__file__).resolve().parents[2]  # processes/<имя>/run.py: корень кабинета
HERE = ROOT / "processes" / SLUG
OUT = ROOT / "output" / SLUG
sys.path.insert(0, str(ROOT / "tools"))
import read_table  # кодировка, шапка и листы как у просмотра таблиц


class StopRun(Exception):
    """Понятная человеку причина остановки: строка по-русски, код выхода 2 (3: файл открыт в другой программе)."""

    def __init__(self, message, code=2):
        super().__init__(message)
        self.code = code


def newest_input(exts=(".csv", ".xlsx", ".txt")):
    folder = ROOT / "input" / SLUG
    files = [p for p in folder.glob("*") if p.is_file() and p.suffix.lower() in exts
             and not p.name.startswith(("~$", "."))]
    if not files:
        raise StopRun(f"В папке input/{SLUG} нет файла. Положите файл и запустите расчёт снова.")
    # Когда файл появился в папке или изменился: копия из Проводника сохраняет старую дату изменения.
    return max(files, key=lambda p: max(p.stat().st_mtime, p.stat().st_ctime))


def number(text):
    """Число из ячейки: «1 234,5» или «1234.5». Не число (и nan, inf, 1_000, 1e5): None."""
    # split() без аргументов убирает любые пробелы, и неразрывный между разрядами в выгрузках 1С тоже.
    t = "".join(str(text).split()).replace(",", ".")
    return float(t) if re.fullmatch(r"[-+]?\d+(\.\d+)?", t) else None


def replace_file(tmp, target):
    """Запись через временный файл: страница не увидит половину файла. Файл открыт: понятная строка, код 3."""
    try:
        os.replace(tmp, target)
    except PermissionError:
        tmp.unlink(missing_ok=True)
        raise StopRun(f"Файл output/{SLUG}/{target.name} открыт в другой программе. "
                      "Закройте его и запустите расчёт снова.", code=3)


def write_excel(name, sheets):
    """Файл Excel output/<имя>/<name>: sheets = {"Лист": (столбцы, строки)}. Возвращает путь для files."""
    try:
        from openpyxl import Workbook
        from openpyxl.styles import Font
    except ImportError:
        raise StopRun("Не найдена библиотека openpyxl для Excel. Скажите Claude «проверь сетап».")
    wb = Workbook()
    wb.remove(wb.active)
    for title, (columns, rows) in sheets.items():
        ws = wb.create_sheet(title[:31])
        ws.append(list(columns))
        for cell in ws[1]:
            cell.font = Font(bold=True)
        for row in rows:
            ws.append(list(row))
        for i, col in enumerate(columns, start=1):
            longest = max([len(str(col))] + [len(str(r[i - 1])) for r in rows if i - 1 < len(r) and r[i - 1] is not None])
            ws.column_dimensions[ws.cell(1, i).column_letter].width = min(max(longest + 2, 8), 60)
        ws.freeze_panes = "A2"
    OUT.mkdir(parents=True, exist_ok=True)
    target = OUT / name
    tmp = target.with_name(target.name + ".tmp")
    wb.save(tmp)
    replace_file(tmp, target)
    return f"output/{SLUG}/{name}"


def write_manual(columns, items):
    """Список «разобрать вручную»: items = [(значения строки файла, почему)]. Пишется всегда, даже пустой."""
    rows = [list(values) + [why] for values, why in items]
    if not rows:
        rows = [["Всё разобрано программой."]]
    return write_excel("razobrat-vruchnuyu.xlsx", {"Разобрать вручную": (list(columns) + ["Почему"], rows)})


def write_result(result):
    OUT.mkdir(parents=True, exist_ok=True)
    tmp = OUT / "result.json.tmp"
    tmp.write_text(json.dumps(result, ensure_ascii=False, allow_nan=False, indent=2), encoding="utf-8")
    replace_file(tmp, OUT / "result.json")


def main():
    src = newest_input()
    table = read_table.analyze(src, None, LIMIT)  # лист: второй аргумент (номер с 1 или имя)
    columns, rows = table["columns"], table["rows"]  # строки данных, значения текстом
    manual = []  # (строка файла, почему): всё, что программа не разобрала сама
    # ... расчёт по скиллу ...
    files = [write_manual(columns, manual)]
    summary = f"... Разобрать вручную: {len(manual)}. Файл {src.name}."
    if table["data_rows"] > len(rows):
        summary += f" Внимание: в файле {table['data_rows']} строк, посчитаны первые {len(rows)}."
    result = {
        "title": TITLE,
        "updated_at": datetime.now().astimezone().isoformat(timespec="seconds"),
        "status": "green",
        "summary": summary,
        "columns": ["..."],
        "rows": [["..."]],
        "files": files,
        # Те же разделы и названия, что в output/<имя>/etalon-skilla.json: по ним идёт сверка с эталоном.
        "sverka": {"итоги": {}, "по категориям": {}, "по строкам": {}},
    }
    write_result(result)
    print(result["summary"])


if __name__ == "__main__":
    for stream in (sys.stdout, sys.stderr):
        stream.reconfigure(encoding="utf-8")
    try:
        main()
    except (StopRun, read_table.UserError) as e:
        print(e, file=sys.stderr)
        sys.exit(e.code if isinstance(e, StopRun) else 2)
```

## Словарь

Словарь лежит рядом с программой: `processes/<имя>/slovar.json`, категория и её слова и фразы. Слово с «?» в конце слабое (`"пол?"`), с «!» признак рекламы (`"выиграйте!"`), ниже. Процесс разбирает обращения, жалобы или заявки: в словаре ещё раздел `"срочно (не тема)"` со словами срочности. В примере ниже он целиком: это слова срочности по умолчанию (опасность для людей и станции, пролив, падение человека, по-русски и по-казахски, основами), бери их в любой такой процесс и добавляй к ним срочное из скилла человека.

Какие слова брать: словарь должен разложить и файл следующей недели, где слова будут другими.

- На тему 8-15 слов, в два прохода: сначала по названию темы, не глядя в строки, 6-8 обычных слов её предмета, которые придут в любую неделю (синонимы, виды товаров и услуг, способы оплаты, типичные предметы и места), потом слова предмета темы из строк файла. Пример из другой работы, тема «зарплата» в обращениях к кадрам: «зарплата», «аванс», «премия», «расчётный», «удержание», «налог».
- Слово в обычной форме, целиком («командировка», не «командиров»): основу программа берёт сама. Обрезанное слово («заправщ») находит только формы, где окончание идёт сразу за ним.
- Слово двух тем только фразой: «расчётный лист» и «больничный лист», не одно «лист».
- Слабое слово помечай «?» в конце: `"касса?"`. Слабое слово без соседних слов тему не говорит: общие действия и состояния («не работает», «ждать», «не принимают», «сломан», «долго») и предметы, о которых пишут в разных темах («касса», «колонка», «чек», «карта», «сотрудник», «вода», «акция»). Сильное слово говорит тему само («бонус», «баллы», «туалет», «самса», «недолив»). Слабым помечай и любое слово, которое по эталону стоит в строке другой темы. Слабое слово тему не решает: строка, где нашлись только слабые слова, уходит в «разобрать вручную» с пометкой «только общее слово: «касса»». Сверка называет слова из строк другой темы строкой «Слабые слова».
- Редкие слова одной строки (цитаты, обороты, описание случая: «закатил глаза», названия моделей телефонов) не бери: на следующей неделе их уже не будет. Строка, которую без них не разобрать, уходит в «разобрать вручную».
- Не подбирай слово под одну строку: слово должно говорить о теме и на другой неделе. Строке, для которой такого слова нет, место в «разобрать вручную».
- Слово рекламы и спама помечай «!» в конце, в той теме, куда скилл кладёт спам: `"выиграйте!"`, `"розыгрыш!"`. Строка со ссылкой (http, https, tg://, www., адрес вида слово.kz, .ru, .com, .net, .org, .me, .ly: bit.ly, t.me, wa.me) получает тему, только если в ней есть такое слово; иначе она уходит в «разобрать вручную» с пометкой «есть ссылка: проверьте, не реклама ли».

Срочность (раздел `"срочно (не тема)"`):

- срочность не тема: тема у строки своя, по словам тем, как у любой строки; слово срочности тему не выбирает и в «разобрать вручную» строку не отправляет;
- принцип: лучше лишнее. Лишняя срочная строка допустима, пропущенная нет;
- слова срочности пишутся основами, а не формами («пролил», «утечк», «травм», «огн», «упал»), и ищутся шире, чем слова тем: слово текста, которое начинается с самого слова срочности («пролил» найдёт «пролили», «упал» найдёт «упали», «улан» найдёт «уланды» и «уланып»), или основа которого начинается с основы слова от пяти букв («травм» найдёт «травмировался», «взрыв» найдёт «взрывоопасно»). У формы с короткой основой («горит»: «гор») только начало слова, иначе «горит» нашло бы «гору». Слово, которое меняется внутри (огонь, огня; қауіп, қаупі), пишется обеими формами. Слово, которое одно ничего не значит, только фразой: «стало плохо», «мне плохо», «без сознания», «сердце прихват», «бьет током», «лопнул шланг», не «плохо», «сердце», «током» («от всего сердца» в благодарности не срочно). По умолчанию в разделе огонь («горит», «загорел», «сгорел», «воспламен», «плам», «полых», «пылает», «вспых», «тлее», «замыкан», «жанып», «от шықты»), гарь («пален», «жжен», «гарь»), насилие («убь», «поджеч», «избил», «ударил», «грозил», «дерутся»), здоровье и падение («упал», «поскользнул», «обмор», «стало плохо», «дурно», «поплох», «кровотеч», «есінен танып»), пролив;
- срочно и без слова срочности: опасное вещество (бензин, топливо, дизель, солярка, газ, масло, мазут; жанармай, май) не дальше шести слов от слова разлива, утечки или запаха (пролил, разлил, течь, течёт, протечка, капает, вытек, льётся, хлещет, хлынул, брызжет, сочится, струя, затопило, лопнул, растекается, лужа, пахнет, воняет; төгілді, ағып, шашылды, шашырап, бүркіп, сасып, иіс; опечатки «бинзин», «бензн» тоже вещество), в любом порядке: «пахнет бензином», «газом пахнет», «лужа бензина у колонки 4, пахнет», «бензин ағып жатыр». Вещество ищется по началу слова, поэтому срочными станут и «газировка пахнет странно», «газета пахнет краской», «газон, пахнет», «маслянистый кофе, запах», «майонез пахнет»: это допустимо. Поэтому «запах» один не срочный («запах от мусорных баков»), а «запах бензина» срочный; «течь бензина» срочно, «течь крыши» нет. Так же перелом: «сломал», «сломана», «сынды» срочно с частью тела не дальше двух слов («сломал ногу», «руку сломала», «аяғы сынды»), «сломался терминал» не срочно (`BREAKS`, `BODY`). Нож и пистолет в срочность не входят: «ножницы» и заправочный пистолет. Вещества и слова разлива в программе (`SUBSTANCES`, `SPILLS`), их можно дополнить;
- отрицание срочность не снимает: «чуть не упал» срочно. Исключения, где огонь не пожар: слово огня («горит», «загорелся», «сгорела», «жанды») после «не» или вплотную к слову лампы без запятой между (лампа, индикатор, табло, «тускло», шам) и «загорелся чек двигателя»: «не горит освещение», «горит индикатор», «горит тускло» не срочные, а «колонка горит, чек не пробили» и «рядом с чеком загорелась бумага» срочные (`FIRE`, `LIGHTS`). Огонь и взрыв в переносном смысле тоже не срочные, только сами обороты: «цены горят», «горят цены», «цены просто горят» («цен» вплотную или через одно слово из «просто», «прямо», «реально», «аж», «очень»), «взорвало цены», «огонь, а не цены», «пламенный привет», «сгорел на работе». Лампа и оборот снимают срочность только со своего слова огня, а если вплотную к нему то, что горит (колонка, машина, касса, проводка, щит, шланг, бак, контейнер, мусор, здание, магазин, кафе, шины, колёса, трава, көлік; `OBJECTS`), не снимают совсем: «Колонка горит цены», «Колонка горит лампа рядом», «загорелась машина цены бензина», «Цены горят и горит колонка» срочные;
- ещё два сочетания: курят рядом с колонкой, бензином, парами, газом («курит у колонки», «закурил рядом с колонкой», `SMOKE`, `SMOKE_NEAR`) и шипит газ или баллон («газовый баллон шипит», `HISS`, `HISS_NEAR`). Места срочности, которые перекрываются, сливаются в одно: «пахнет бензином на асфальте лужа»;
- итог карточки процесса со словарём кончается советом «Новый файл: скажите Claude «пополни словарь процесса <название>».»: остальное срочное, которого слова не нашли, Claude найдёт по смыслу при пополнении (run-process, «Пополнить словарь», шаг 3);
- строка, где есть слово срочности: `row_status` `red`, `row_note` «срочно: <найденные слова текста>» (у строки без темы ещё «; разобрать вручную»). Карточка `red`, если есть срочные строки; итог начинается с «Срочно: N (№ ...)». На карточке срочные строки идут первыми, строка с бо́льшим числом слов срочности выше. В Excel результата лист «Срочно» (только при разделе срочности в словаре). Повтор не срочный: срочный его первый раз. Раздел можно назвать и коротко, `"срочно"`: программа поймёт;
- срочное из скилла человека пиши словами самого скилла (скилл пишет «курение у колонок»: «курение», «курит»). Слова из строк файла в срочность не бери: «лужа» из одной строки на новой неделе красит обычные строки. Только строку, срочную по эталону, которую не нашли ни слова по умолчанию, ни слова скилла, ни правило о веществе, находи одним словом предмета опасности из неё («курил»);
- слова срочности ловят и лишнее («пролили кофе», «машина дымит», «подтекает пистолет», «топливо пахнет странно», «вечером опасно» о тёмном въезде). Слово, которое только начинается как слово срочности, а значит другое, исключено в программе (`NOT_URGENT`: «искренне» не «искры»): это допустимо, срочное лучше проверить лишний раз, чем пропустить пролив.

Правило совпадения (его же простыми словами объясняй человеку):

- большие и маленькие буквы и буква ё не важны;
- программа сравнивает основы: и у слова словаря, и у слова текста она отбрасывает окончание и простой суффикс (-к-, -н-, -ость), поэтому слово в обычной форме находит другие формы: «командировка» найдёт «командировки» и «командировочные», «бонус» найдёт «бонусы» и «бонусов»;
- слово находит и слово текста, которое начинается с него, если дальше идёт только окончание: русское («запах» найдёт «запахом», «газ» найдёт «газа» и «газовой») или казахское («дәретхана» найдёт «дәретханада», «ұпай» найдёт «ұпайлары»). Чужое слово с тем же началом не находится: «газ» не найдёт «газету» и «газон», «балл» не найдёт «баллон», «пол» не найдёт «полицию» и «полный», «колонка» не найдёт «колонну», «касса» не найдёт «кассира», «қызмет» не найдёт «қызметкер»;
- слово из одной-двух букв (ДТ, QR) ищется только целиком;
- фраза из нескольких слов находит эти слова подряд: «не работает», «аи 92» (найдёт и «АИ-92»);
- если слово меняется внутри (санузел, санузлы), в словарь пишут обе формы;
- категория строки: та, у которой нашлось больше разных сильных слов и фраз из словаря (без «?»; слова с одной основой, «аванс» и «авансы», считаются одним). Нашлась и другая тема: тема остаётся, строка с пометкой «тема по перевесу слов, есть и «Y»» (`row_status` `info`);
- отрицание: слово темы, перед которым стоит «не» (и между ними одно из «очень», «слишком», «совсем», «особо», «сильно») или после которого «емес», за тему не считается («не вежлив», «не очень вежлив», «сыпайы емес»). «Нет», «без», «жоқ» говорят, что предмета нет, а тема та же («Нет детского питания»: минимаркет), это не отрицание. Есть другое сильное слово: тема по нему. Нет: строка уходит в «разобрать вручную» с пометкой «отрицание: «не вежлив»». Слово, которое в той же строке стоит и без отрицания, считается;
- ссылка в тексте: тема только по слову с «!», иначе «разобрать вручную» с пометкой «есть ссылка: проверьте, не реклама ли»;
- сильных слов поровну у двух тем и больше: строка уходит в «разобрать вручную» с пометкой «две темы: X, Y» (темы по порядку в тексте; одно и то же слово в двух темах стоит на одном месте: по алфавиту). Сильных слов нет, только слабые (с «?»): в «разобрать вручную» с пометкой «только общее слово: «касса»» («только общие слова: «касса», «чек»»). В итоге карточки счёт этих причин: «Разобрать вручную: N, из них две темы a, только общие слова b, отрицание c, ссылка d». Ничего не нашлось или текст пустой: «разобрать вручную» с причиной. SMOKE = ("курит", "курил", "курят", "курен", "закур", "зажигалк", "чиркнул")
SMOKE_NEAR = ("колонк", "бензин", "пары", "паров", "топлив", "газ")
HISS = ("шипит", "шипел", "шипят")
HISS_NEAR = ("газ", "баллон")
NOT_URGENT = ("искренн",)  # слова, которые начинаются как слова срочности, но о другом: «искренне» не «искры»
# «Горит», «загорелся», «жанды» о лампе и табло не пожар: после «не» или вплотную к слову лампы, без знака
# препинания между («не горит освещение», «горит индикатор», «горит тускло», «загорелся чек двигателя», «шам жанды»).
FIRE = ("гор", "загор", "сгор", "жан")
LIGHTS = ("ламп", "индикатор", "табло", "тускл", "шам")
# Огонь и взрыв в переносном смысле, только сами обороты в одной части фразы (not_fire): «цены (просто) горят»,
# «взорвало цены», «огонь, а не цены», «пламенный привет», «сгорел на работе».
FIERY = FIRE + ("огон", "огн", "взрыв", "взорв", "плам", "пыла", "полых", "вспых")
ADVERBS = ("просто", "прямо", "реально", "аж", "очень")  # одно между «цены» и «горят»: «цены просто горят»
# Что горит: такое слово вплотную к слову огня (и без запятой) отменяет исключения лампы и оборота: «колонка горит».
OBJECTS = ("колонк", "машин", "авто", "касс", "проводк", "щит", "шланг", "бак", "контейнер", "мусор", "здани",
           "магазин", "кафе", "шин", "колес", "трав", "көлік")
VOWELS = set("аеиоуыэюяйьъәіөұүі")
KAZ_LETTERS = set("әғқңөұүһі")
# Основа слова: окончание и простой суффикс прочь, как в стеммере Snowball для русского, упрощённо.
REFLEXIVE = ("ся", "сь")
ADJECTIVE = ("ими", "ыми", "его", "ого", "ему", "ому", "ее", "ие", "ые", "ое", "ей", "ий", "ый", "ой",
             "ем", "им", "ым", "ом", "их", "ых", "ую", "юю", "ая", "яя", "ою", "ею")

VERB = ("ейте", "уйте", "ила", "ыла", "ена", "ите", "или", "ыли", "ило", "ыло", "ено", "ует", "уют", "ены", "ить",
        "ыть", "ишь", "ей", "уй", "ил", "ыл", "им", "ым", "ен", "ят", "ит", "ыт", "ую", "ю")

# Что может стоять в слове текста сразу после слова словаря: русское окончание («запах», «запахом»)
ENDINGS = set(REFLEXIVE + ADJECTIVE + VERB_AFTER_A + VERB + NOUN)
# или казахские окончания, до трёх подряд («дәретхана», «дәретханада»; «ұпай», «ұпайлары»).
KAZ_ENDINGS = ("лар", "лер", "дар", "дер", "тар", "тер", "ның", "нің", "дың", "дің", "тың", "тің", "ға", "ге", "қа",
               "ке", "на", "не", "а", "е", "ны", "ні", "ды", "ді", "ты", "ті", "н", "да", "де", "та", "те", "нда", "нде",
               "дан", "ден", "тан", "тен", "нан", "нен", "мен", "бен", "пен", "ым", "ім", "м", "ың", "ің", "ң", "ы",
               "і", "сы", "сі", "ымыз", "іміз", "мыз", "міз", "ңыз", "ңіз", "ыңыз", "іңіз", "сыз", "сіз", "лы", "лі",
               "ғы", "гі", "қы", "кі", "дағы", "дегі", "тағы", "тегі")

# «разбавлен» и «разбавленный», «качество» и «качественный».
DERIV = ("ов", "ев", "оч", "еч", "ик", "щик", "чик", "енн", "анн")


def words_of(text):
    """Слова текста строчными, ё как е: буквы и цифры, остальное разделители."""
    return re.findall(r"[^\W_]+", str(text).lower().replace("ё", "е"))


def cut(word, endings, keep=3, after=""):
    """(слово без самого длинного подходящего окончания, отрезано ли). Остаётся не меньше keep букв."""
    for e in sorted(endings, key=len, reverse=True):
        if word.endswith(e) and len(word) - len(e) >= keep and (not after or word[-len(e) - 1] in after):
            return word[:-len(e)], True
    return word, False


def stem(word):
    """Основа слова: одна и та же у «зарядка», «зарядки», «зарядные». Слово до трёх букв не меняется.
    Казахские слова: та же функция у словаря и у текста, а окончания после слова находит same_root."""
    w = str(word).lower().replace("ё", "е")
    if len(w) <= 3:
        return w
    w, _ = cut(w, REFLEXIVE)
    for group, after in ((ADJECTIVE, ""), (VERB_AFTER_A, "ая"), (VERB, ""), (NOUN, "")):
        w, done = cut(w, group, after=after)
        if done:
            break
    short, done = cut(w, SUFFIX, keep=4)
    # «колонк» → «колон», но «машин» не → «маши», и «колонн» (колонна) не → «колон».
    if done and short[-1] not in VOWELS and not (w.endswith("н") and short.endswith("н")):
        w = short
    while len(w) > 3 and w[-1] in VOWELS:
        w = w[:-1]
    return w


def load_slovar():
    """{категория: [(слово или фраза, [основы])]}, слова срочности под ключом URGENT. Испорчен: понятная остановка."""
    rel = f"processes/{SLUG}/slovar.json"
    try:
        data = json.loads(SLOVAR.read_text(encoding="utf-8-sig"))
    except FileNotFoundError:
        raise StopRun(f"Нет словаря {rel}. Скажите Claude «доработай {TITLE}».")
    except ValueError as e:
        raise StopRun(f"Словарь {rel} испорчен (строка {e.lineno if hasattr(e, 'lineno') else '?'}): проверьте кавычки и запятые "
                      f"или скажите Claude «доработай {TITLE}».")
    if not isinstance(data, dict) or not all(isinstance(v, list) for v in data.values()):
        raise StopRun(f"В словаре {rel} нужен вид {{\"категория\": [\"слово\", \"фраза\"]}}.")
    slovar = {}
    for cat, entries in data.items():
        name = URGENT if " ".join(words_of(cat)) in URGENT_NAMES else str(cat)
        slovar[name] = [(str(e).strip(), roots(e)) for e in entries if words_of(e)]
    return slovar


def roots(text):
    """[(основа, слово)] для каждого слова текста или записи словаря."""
    return [(stem(w), w) for w in words_of(text)]


def kaz_tail(rest, depth=3):
    """Остаток слова: казахские окончания подряд, не больше трёх."""
    if not rest:
        return True
    return depth > 0 and any(rest.startswith(k) and kaz_tail(rest[len(k):], depth - 1) for k in KAZ_ENDINGS)


def same_root(entry, word):
    """Слово словаря и слово текста, оба (основа, слово). Слово из одной-двух букв: только целиком. Совпадают:
    та же основа; слово текста это слово словаря и окончание (русское или казахское; казахское у слова с казахской
    буквой или от пяти букв); основа текста это основа словаря и суффикс из DERIV; основы отличаются суффиксом -н-."""
    s, e = entry
    ws, w = word
    if len(e) <= 2:
        return w == e
    if ws == s:
        return True
    if w.startswith(e):
        rest = w[len(e):]
        if rest in ENDINGS or ((KAZ_LETTERS & set(w) or len(e) >= 5) and kaz_tail(rest)):
            return True
    if ws.startswith(s) and ws[len(s):] in DERIV:
        return True
    short, long = sorted((s, ws), key=len)
    return len(short) >= 4 and long == short + "н" and not short.endswith("н")  # «благодарн» и «благодар»


def broad_root(entry, word):
    """Совпадение для слов срочности, шире same_root: лишняя срочная строка лучше пропущенной. Слово текста
    начинается со слова словаря, или его основа с основы словаря от пяти букв («травм» и «травмировался»)."""
    s, e = entry
    ws, w = word
    if len(e) <= 2:
        return w == e
    if w.startswith(NOT_URGENT):
        return False
    if w.startswith(e):
        return True
    if len(s) <= 3 < len(e):  # у формы короткая основа («горит»: «гор»): только по началу слова, не «гору»
        return False
    return same_root(entry, word) or (len(s) >= 5 and ws.startswith(s))


def find_all(entry, words, match=same_root):
    """Номера мест в тексте, где стоит слово или фраза из словаря (номер первого слова). Фраза: слова подряд."""
    n = len(entry)
    return [i for i in range(len(words) - n + 1) if all(match(e, w) for e, w in zip(entry, words[i:i + n]))]


def phrase(words, i, j):
    """Слова текста с i по j включительно, как в тексте (строчными)."""
    return " ".join(w for _, w in words[max(i, 0):j + 1])


def negation(words, i, n):
    """Отрицание у слова словаря на месте i (n слов): «не вежлив», «не очень вежлив» (одно усиление между),
    «сыпайы емес». Нет отрицания: ""."""
    if i > 0 and words[i - 1][1] in NEGATION_BEFORE:
        return phrase(words, i - 1, i + n - 1)
    if i > 1 and words[i - 1][1] in INTENSIFIERS and words[i - 2][1] in NEGATION_BEFORE:
        return phrase(words, i - 2, i + n - 1)
    if i + n < len(words) and words[i + n][1] in NEGATION_AFTER:
        return phrase(words, i, i + n)
    return ""


def topic_hits(text, slovar):
    """{тема: (где первое слово, сколько разных сильных основ, найденные слова словаря, [(где, отрицание)])} по всем
    темам, без срочности. Сильное слово: без «?» в конце. Слово, которое в тексте стоит только с отрицанием,
    в найденные не идёт, оно в списке отрицаний."""
    words = roots(text)
    found = {}
    for cat, entries in slovar.items():
        if cat == URGENT:
            continue  # срочность не тема
        first, strong, hit, neg = len(words), set(), [], []
        for entry, parts in entries:
            places = find_all(parts, words)
            free = [i for i in places if not negation(words, i, len(parts))]
            if places and not free:
                neg.append((places[0], negation(words, places[0], len(parts))))
            elif free:
                first = min(first, free[0])
                hit.append(entry)
                if not entry.endswith(WEAK):
                    strong.add(tuple(s for s, _ in parts))
        if hit or neg:
            found[cat] = (first, len(strong), hit, neg)
    return found


def several(cats):
    """Пометка «две темы: X, Y» (три и больше: «несколько тем: ...»)."""
    return (TIES[0] if len(cats) == 2 else TIES[1]) + ": " + ", ".join(cats)


def classify(text, slovar):
    """(категория, пометка, найденные слова словаря). Ссылка в тексте: тема только по слову с «!», иначе MANUAL
    с пометкой LINK. Тема: больше разных сильных слов; нашлась и другая тема: «тема по перевесу слов, есть и «Y»».
    Сильных поровну у двух тем и больше: MANUAL, «две темы: X, Y» (по месту в тексте, одно место: по алфавиту).
    Сильных нет: MANUAL, «отрицание: «не вежлив»» или «только общее слово: «касса»». Слов нет: MANUAL, почему."""
    if not words_of(text):
        return MANUAL, "пустой текст", []
    found = topic_hits(text, slovar)
    hits = {cat: h for cat, h in found.items() if h[2]}  # темы, где слово нашлось без отрицания
    order = [cat for _, cat in sorted((h[0], cat) for cat, h in hits.items())]  # по месту в тексте
    every = [e for cat in order for e in hits[cat][2]]
    if LINK_RE.search(str(text)):  # ссылка: тему даёт только признак рекламы, иначе решает человек
        ads = [cat for cat in order if any(e.endswith(AD) for e in hits[cat][2])]
        return (ads[0], "", hits[ads[0]][2]) if ads else (MANUAL, LINK, every)
    best = max((h[1] for h in hits.values()), default=0)
    if best == 0:  # сильных слов нет: тему решит человек
        neg = [f for _, f in sorted(n for h in found.values() for n in h[3])]
        if neg:
            return MANUAL, NEGATED + ": " + ", ".join(f"«{f}»" for f in dict.fromkeys(neg)), every
        if not every:
            return MANUAL, "нет слов из словаря", []
        hit = list(dict.fromkeys(every))
        words = ", ".join(f"«{h.rstrip(WEAK).strip()}»" for h in hit)
        return MANUAL, (WEAK_ONLY[0] if len(hit) == 1 else WEAK_ONLY[1]) + ": " + words, hit
    top = [cat for cat in order if hits[cat][1] == best]
    if len(top) > 1:  # сильных слов поровну
        return MANUAL, several(top), [e for cat in top for e in hits[cat][2]]
    others = [cat for cat in order if cat != top[0]]
    note = "тема по перевесу слов, есть и " + ", ".join(f"«{c}»" for c in others) if others else ""
    return top[0], note, hits[top[0]][2]


def places(stems, words):
    """Номера слов текста, которые находит одна из основ (как слова срочности, broad_root)."""
    return [i for w in stems for i in find_all(roots(w), words, broad_root)]


def near_pairs(words, firsts, seconds, near):
    """Места «второе слово и ближайшее к нему первое не дальше near слов»: «пахнет газом», «сломал ногу»."""
    spans = []
    for j in seconds:
        close = [i for i in firsts if i != j and abs(i - j) <= near]
        if close:
            i = min(close, key=lambda i: (abs(i - j), i))
            spans.append((min(i, j), max(i, j)))
    return spans


def clauses(text):
    """Номер части фразы у каждого слова текста (как words_of): знак препинания между словами начинает новую."""
    t = str(text).lower().replace("ё", "е")
    ids, part, last = [], 0, 0
    for m in re.finditer(r"[^\W_]+", t):
        if ids and re.search(r"[,.;:!?()\u2013\u2014]", t[last:m.start()]):
            part += 1
        ids.append(part)
        last = m.end()
    return ids


def not_fire(words, part, i, j):
    """Место срочности не о пожаре: слово огня после «не» или вплотную к слову лампы без запятой («не горит
    освещение», «лампа горит тускло», «загорелся чек двигателя», «шам жанды») и обороты в переносном смысле:
    «цены горят», «цены просто горят», «горят цены», «взорвало цены», «огонь, а не цены», «пламенный привет»,
    «сгорел на работе». Рядом с огнём то, что горит («колонка горит», «загорелась машина»): исключения лампы
    и оборота не действуют. Снимается только это слово огня: «Цены горят и горит колонка» срочно."""
    if i != j:
        return False
    w = words[i][1]
    word = lambda k: words[k][1] if 0 <= k < len(words) and part[k] == part[i] else ""
    if w.startswith(FIRE) and word(i - 1) in NEGATION_BEFORE:
        return True
    if not w.startswith(FIERY):
        return False
    beside = [words[k][1] for k in (i - 1, i + 1) if 0 <= k < len(words)]
    if any(b.startswith(OBJECTS) for b in beside):  # «колонка горит», «загорелась машина»: пожар
        return False
    if w.startswith(FIRE):
        if word(i - 1).startswith(LIGHTS) or word(i + 1).startswith(LIGHTS):
            return True
        if word(i + 1).startswith("чек") and word(i + 2).startswith("двигател"):
            return True
    for step in (-1, 1):  # «цены горят», «горят цены», «цены просто горят»
        near, far = word(i + step), word(i + 2 * step)
        if near.startswith("цен") or near in ADVERBS and far.startswith("цен"):
            return True
    if w.startswith("плам") and word(i + 1).startswith("привет"):
        return True
    if w.startswith("сгор") and word(i + 1) == "на" and word(i + 2).startswith("работ"):
        return True
    rest = [x for _, x in words[i + 1:i + 4]]
    return w.startswith(("огон", "огн")) and rest[:2] == ["а", "не"] and len(rest) == 3 and rest[2].startswith("цен")


def urgent_words(text, slovar):
    """Места текста, по которым строка срочная, по порядку в тексте: слова срочности (ищутся шире, broad_root)
    и опасное вещество рядом со словом разлива, утечки, запаха («пахнет бензином»). Отрицание здесь не снимает
    срочность: лишняя срочная строка дешевле пропущенной. Раздела срочности в словаре нет: []."""
    if URGENT not in slovar:
        return []
    words = roots(text)
    spans = [(i, i + len(parts) - 1) for _, parts in slovar[URGENT] for i in find_all(parts, words, broad_root)]
    stuff, spill = places(SUBSTANCES, words), places(SPILLS, words)
    spans += near_pairs(words, stuff, spill, NEAR)
    spans += near_pairs(words, places(BODY, words), places(BREAKS, words), 2)
    spans += near_pairs(words, places(SMOKE_NEAR, words), places(SMOKE, words), NEAR)
    spans += near_pairs(words, places(HISS_NEAR, words), places(HISS, words), NEAR)
    part = clauses(text)
    spans = [a for a in spans if not not_fire(words, part, *a)]
    keep = []  # места, которые перекрываются, сливаем в одно: «бензин иісі», «пахнет бензином на асфальте лужа»
    for i, j in sorted(set(spans)):
        if keep and i <= keep[-1][1]:
            keep[-1] = (keep[-1][0], max(keep[-1][1], j))
        else:
            keep.append((i, j))
    return list(dict.fromkeys(phrase(words, i, j) for i, j in keep))

        items.append({"num": num, "azs": azs, "text": text, "cat": cat, "why": why, "found": found,
                      "hot": urgent_words(text, slovar),
                      "hits": {c: h[2] for c, h in topic_hits(text, slovar).items() if h[2]}})  # для сверки
    # На карточке первыми срочные (больше слов срочности выше), потом «разобрать вручную», дальше по порядку файла.
    items.sort(key=lambda x: (-len(x["hot"]), x["cat"] != MANUAL))
    hot = [x for x in items if x["hot"]]

    def note(x):  # пометка строки на карточке: срочно; разобрать вручную, две темы или только общее слово
        marks = ["срочно: " + ", ".join(x["hot"])] if x["hot"] else []
        if x["cat"] == MANUAL:
            marks.append(x["why"] if x["why"].startswith(MANUAL_NOTES) else MANUAL)
        elif x["cat"] != "повтор" and x["why"]:
            marks.append(x["why"])
        return "; ".join(marks) or None

    def excel_note(x):  # пометка в Excel: срочно и почему (причина «разобрать вручную», две темы, повтор)
        return "; ".join(m for m in ("срочно: " + ", ".join(x["hot"]) if x["hot"] else "", x["why"]) if m) or None

    by_cat, by_azs = {}, {}
    for x in items:
        if x["cat"] in ("повтор", MANUAL):
            continue
        by_cat[x["cat"]] = by_cat.get(x["cat"], 0) + 1
        by_azs[x["azs"]] = by_azs.get(x["azs"], 0) + 1
    out_cols = ["№", "АЗС", "Тема", "Текст"]
    line = lambda x: [x["num"], x["azs"], x["cat"], x["text"]]
    sheets = {}
    if URGENT in slovar:  # лист «Срочно» первым, только если в словаре есть раздел срочности
        sheets["Срочно"] = (out_cols + ["Слово срочности"], [line(x) + [", ".join(x["hot"])] for x in hot])
    sheets["Обращения"] = (out_cols + ["Найдено по слову", "Пометка"],
                           [line(x) + [", ".join(x["found"]) or None, excel_note(x)] for x in items])
    sheets["Сводка"] = (["Тема", "Обращений"], sorted(by_cat.items(), key=lambda kv: -kv[1]))
    sheets["По АЗС"] = (["АЗС", "Обращений"], sorted(by_azs.items()))
    files = [write_excel("obrashcheniya-po-temam.xlsx", sheets), write_manual(columns, manual)]
    repeats = sum(1 for x in items if x["cat"] == "повтор")
    kinds = {name: sum(1 for x in items if x["cat"] == MANUAL and x["why"].startswith(start)) for name, start in
             (("две темы", TIES), ("только общие слова", WEAK_ONLY), ("отрицание", NEGATED), ("ссылка", LINK))}
    top = ", ".join(f"{c} {n}" for c, n in sorted(by_cat.items(), key=lambda kv: -kv[1])[:3])
    head = ""
    if URGENT in slovar:  # итог начинается со срочного
        head = f"Срочно: {len(hot)}" + (f" (№ {', '.join(x['num'] for x in hot)}). " if hot else ". ")
    summary = (f"{head}Обращений {len(rows)}, повторов {repeats}. Чаще всего: {top}. Разобрать вручную: "
               f"{len(manual)}, из них " + ", ".join(f"{k} {n}" for k, n in kinds.items()) +
               f" (файл razobrat-vruchnuyu.xlsx). Файл {src.name}. "
               f"Новый файл: скажите Claude «пополни словарь процесса {TITLE}».")
    result = {
        "title": TITLE,
        "updated_at": datetime.now().astimezone().isoformat(timespec="seconds"),
        "status": "red" if hot else "green",  # есть срочные строки: карточка красная
        "summary": summary,
        "columns": out_cols,
        "rows": [line(x) for x in items],
        "row_status": ["red" if x["hot"] else "info" if note(x) else None for x in items],
        "row_note": [note(x) for x in items],
        "files": files,
        "sverka": {
            "итоги": {"обращений": len(rows), "повторов": repeats},
            "по категориям": by_cat,
            "по строкам": {x["num"]: x["cat"] for x in items},
            "срочно": [x["num"] for x in hot],
            "найдено": {x["num"]: x["hits"] for x in items if x["hits"]},  # слова по темам: подсказка сверки
        },
    }
    write_result(result)
    print(result["summary"])

## Шаблон Word

Шаблон лежит рядом с программой: `processes/<имя>/shablon.docx`. Поле в шаблоне пишется в двойных фигурных скобках: `{{Наименование поставщика}}`. Человек может открыть шаблон в Word и поправить текст; поля оставляет как есть, кроме своих данных (подпись, имя, должность, телефон): их он один раз печатает в шаблоне вместо поля, и дальше они идут обычным текстом. Поля заполняются везде: в тексте, таблицах, надписях, элементах управления, во всех колонтитулах (и первой страницы бланка). Поле, до которого замена не достала, программа находит после заполнения и отправляет документ в «разобрать вручную». Оформление текста вокруг поля сохраняется.

Шаблона ещё нет: программа делает его сама при первом запуске:

- есть шаблон человека в `input/<имя>/`: в `SOURCE_TEMPLATE` имя этого файла. Программа берёт его целиком (оформление, бланк) и превращает поля в квадратных скобках в поля шаблона: `[дата]` станет `{{дата}}`;
- шаблона человека нет: текст шаблона из скилла в `SHABLON_TEXT`, по строке на абзац, поля в `{{...}}`.

Заполнение: `fill_docx(values, имя файла)`, где `values` это `{"поле": значение}`. Поле без данных (нет в `values`, `None` или пустая строка) получает пометку `NO_DATA`. Пометку бери из скилла человека: скилл пишет «[уточнить]» или «[уточнить: что]», и программа пишет так же (`NO_DATA = "[уточнить]"`, пояснение для одного поля значением `"[уточнить: номер договора]"`); в скилле пометки нет: «[нет данных]». Любой документ, где после заполнения осталась пометка (поле без данных, значение с пометкой, пометка в тексте самого шаблона), программа кладёт в «разобрать вручную» с перечнем таких полей. Свои данные человека (подпись, имя, должность, телефон) программа не заполняет и в `values` их нет: пока человек не впечатал их в шаблон вместо поля, в документе пометка, и документ в «разобрать вручную». Таблицу (список строк, первая строка: заголовки) можно поставить в поле, которое стоит в абзаце одно: на его месте будет таблица. Документы пиши в `output/<имя>/`, имена файлов латиницей: `pismo-01.docx`.

```python
# --- Шаблон Word: черновики по processes/<имя>/shablon.docx ---
NO_DATA = "[нет данных]"  # пометка поля без данных; скилл человека пишет «[уточнить]»: здесь "[уточнить]"
TEMPLATE = HERE / "shablon.docx"
SOURCE_TEMPLATE = ""  # шаблон человека в input/<имя>/, например "pismo.docx"; нет такого файла: ""
SHABLON_TEXT = [  # шаблон из текста скилла, по строке на абзац; нужен, только если SOURCE_TEMPLATE пустой
    "{{Кому}}",
    "Уважаемые коллеги!",
    "{{Текст}}",
]
FIELD_RE = re.compile(r"\{\{\s*([^{}]+?)\s*\}\}")
BRACKET_RE = re.compile(r"\[([^\[\]]+)\]")
# Пометка в документе: NO_DATA, «[уточнить]», «[нет данных]», и с пояснением: «[уточнить: номер договора]».
MARK_RE = re.compile(r"\[\s*(?:уточнить|нет данных|%s)\s*(?::[^\[\]]*)?\]"
                     % re.escape(NO_DATA.strip("[] ").split(":")[0].strip().lower()), re.I)
# Части документа с текстом: основной текст, все колонтитулы (и первой страницы, и чётных), сноски.
WORD_PARTS = re.compile(r"^/word/(document|header\d*|footer\d*|footnotes|endnotes)\.xml$")
# Куски текста абзаца, и внутри ссылок, правок, полей и элементов управления содержимым.
RUN_PATH = ("./w:r | ./w:hyperlink/w:r | ./w:ins/w:r | ./w:smartTag/w:r | ./w:fldSimple/w:r"
            " | ./w:customXml/w:r | ./w:sdt/w:sdtContent/w:r")


def load_docx():
    try:
        import docx
    except ImportError:
        raise StopRun("Не найдена библиотека python-docx для Word. Скажите Claude «проверь сетап».")
    return docx


def word_parts(doc):
    for part in doc.part.package.iter_parts():
        if WORD_PARTS.match(str(part.partname)):
            yield part


def paragraphs(doc):
    """Все абзацы документа: текст, таблицы, надписи, элементы управления, все колонтитулы, сноски."""
    from docx.oxml.ns import qn
    from docx.text.paragraph import Paragraph
    for part in word_parts(doc):
        root = part.element if hasattr(part, "element") else None  # часть без разбора python-docx: её проверяет leftover_fields
        if root is not None:
            for p in root.iter(qn("w:p")):
                yield Paragraph(p, part)


def replace_fields(p, pattern, func):
    """Замена полей в абзаце. Поле внутри одного куска текста заменяется в нём. Поле, которое Word разбил
    на несколько кусков, собирается в первый из них, а остальные куски этого поля укорачиваются:
    текст вне полей и его оформление (жирный, курсив) не меняются."""
    from docx.text.run import Run
    pos = 0
    while True:
        runs = [Run(r, p) for r in p._p.xpath(RUN_PATH)]
        texts = [r.text for r in runs]
        m = pattern.search("".join(texts), pos)
        if not m:
            return
        new = func(m)
        starts, at = [], 0
        for t in texts:
            starts.append(at)
            at += len(t)
        first = next(i for i, t in enumerate(texts) if starts[i] <= m.start() < starts[i] + len(t))
        last = next(i for i, t in enumerate(texts) if starts[i] < m.end() <= starts[i] + len(t))
        if first == last:
            t = texts[first]
            runs[first].text = t[:m.start() - starts[first]] + new + t[m.end() - starts[first]:]
        else:
            runs[first].text = texts[first][:m.start() - starts[first]] + new
            for i in range(first + 1, last):
                runs[i].text = ""
            runs[last].text = texts[last][m.end() - starts[last]:]
        pos = m.start() + len(new)


def doc_texts(doc):
    """Текст каждого абзаца во всех частях документа, и в тех, что python-docx не разбирает (сноски)."""
    from docx.oxml.ns import qn
    texts = []
    for part in word_parts(doc):
        root = part.element if hasattr(part, "element") else None
        if root is not None:
            texts += ["".join(t.text or "" for t in p.iter(qn("w:t"))) for p in root.iter(qn("w:p"))]
        else:
            xml = part.blob.decode("utf-8", "replace")
            texts += ["".join(re.findall(r"<w:t(?:\s[^>]*)?>([^<]*)</w:t>", x))
                      for x in re.findall(r"<w:p[ >].*?</w:p>", xml, re.S)]
    return texts


def leftover_fields(doc):
    """Поля {{...}}, которые остались в документе после заполнения (в любой части, и в сносках)."""
    return [f.strip() for t in doc_texts(doc) for f in FIELD_RE.findall(t)]


def ensure_template():
    """processes/<имя>/shablon.docx: есть, берём его (человек мог поправить его в Word). Нет: делаем."""
    if TEMPLATE.is_file():
        return TEMPLATE
    docx = load_docx()
    if SOURCE_TEMPLATE:
        src = ROOT / "input" / SLUG / SOURCE_TEMPLATE
        if not src.is_file():
            raise StopRun(f"Нет шаблона input/{SLUG}/{SOURCE_TEMPLATE}. Положите его в папку и запустите снова.")
        doc = docx.Document(src)
        for p in list(paragraphs(doc)):
            replace_fields(p, BRACKET_RE, lambda m: "{{" + m.group(1).strip() + "}}")
    else:
        doc = docx.Document()
        for line in SHABLON_TEXT:
            doc.add_paragraph(line)
    tmp = TEMPLATE.with_name(TEMPLATE.name + ".tmp")
    doc.save(tmp)
    os.replace(tmp, TEMPLATE)
    return TEMPLATE


def field_key(name):
    return " ".join(str(name).lower().replace("ё", "е").split())


def put_table(doc, p, rows):
    """Таблица на месте абзаца с полем: rows = список строк, первая строка заголовки."""
    width = max(len(r) for r in rows)
    table = doc.add_table(rows=0, cols=width)
    try:
        table.style = "Table Grid"
    except Exception:
        pass  # в шаблоне человека нет такого стиля: таблица без рамок
    for r in rows:
        cells = table.add_row().cells
        for i, v in enumerate(r):
            cells[i].text = "" if v is None else str(v)
    p._p.addprevious(table._tbl)
    if p._p.getparent().tag.endswith("}tc"):
        p.text = ""  # ячейка Word должна кончаться абзацем: он остаётся после таблицы пустым
    else:
        p._p.getparent().remove(p._p)


def fill_docx(values, name):
    """Документ output/<имя>/<name> по шаблону. Возвращает (путь для files, поля с пометкой).

    Поле без данных получает NO_DATA. Документ, где после заполнения осталась пометка (поле без данных,
    значение с пометкой «[уточнить: ...]», пометка в тексте самого шаблона), программа отдаёт человеку."""
    docx = load_docx()
    doc = docx.Document(ensure_template())
    known = {field_key(k): v for k, v in values.items()}
    missing, marked = [], []

    def value(m):
        v = known.get(field_key(m.group(1)))
        if v is None or isinstance(v, list) or not str(v).strip():
            v = NO_DATA
        found = MARK_RE.findall(str(v))
        if found:
            missing.append(m.group(1).strip())
            marked.extend(found)
        return str(v)

    for p in list(paragraphs(doc)):
        m = FIELD_RE.fullmatch(p.text.strip())
        v = known.get(field_key(m.group(1))) if m else None
        if isinstance(v, list) and v:
            put_table(doc, p, v)
        else:
            replace_fields(p, FIELD_RE, value)
    missing += leftover_fields(doc)  # поле там, куда замена не достаёт: документ тоже человеку
    left = [mk for t in doc_texts(doc) for mk in MARK_RE.findall(t)]
    for mk in marked:  # пометки, которые поставили поля, уже названы по имени поля
        if mk in left:
            left.remove(mk)
    missing += left  # пометка в тексте шаблона или в ячейке таблицы: документ тоже человеку
    OUT.mkdir(parents=True, exist_ok=True)
    target = OUT / name
    tmp = target.with_name(target.name + ".tmp")
    doc.save(tmp)
    replace_file(tmp, target)
    return f"output/{SLUG}/{name}", sorted(set(missing))


def money(v):
    """Сумма для письма: 1250000 → «1 250 000,00». None: None (поле получит пометку NO_DATA)."""
    if v is None:
        return None
    return f"{v:,.2f}".replace(",", " ").replace(".", ",")
```

## Данные из интернета

Программа может брать данные из интернета: цены на топливо, отзывы, курсы валют, данные сайтов, любые адреса, которые назвал человек. Правила:

- Файлы человека и данные из них программа в ИИ-модели не отправляет: никаких API моделей (OpenAI, Anthropic, Gemini, GigaChat, YandexGPT и подобных), ключей API в программе нет. Анализ делает сама программа.
- Пароли, логины и ключи доступа в программу не пиши. Сайт требует входа: скажи человеку, что программа такие данные взять не может, и предложи выгрузку файлом.
- Каждый запрос с ограничением времени и понятной причиной, если сайт не ответил. Ответ не разобрался (сайт поменял вёрстку): строка в «разобрать вручную» с адресом, не угадывай.
- Адреса и что с них берётся: постоянные в начале программы (`SOURCES`), чтобы человек их видел и мог поправить.
- Страница, которая собирается в браузере (часть отзывов и карт), простым запросом не читается: в ответе нет нужных данных. Скажи об этом человеку на шаге проверки и предложи другой источник или выгрузку файлом.
- Время запроса и адрес источника пиши в итог карточки: «цены с oilclub.kz на 29.10.2026 18:40».

Блок, вставь после функций основы:

```python
# --- Данные из интернета ---
import ssl
import urllib.error
import urllib.request

SOURCES = {"цены": "https://example.kz/prices"}  # что берём и откуда; человек может поправить адрес
TIMEOUT = 30


def fetch(url):
    """Текст страницы по адресу. Не ответил или ошибка: StopRun с понятной причиной."""
    req = urllib.request.Request(url, headers={"User-Agent": "Mozilla/5.0 (cabinet)"})
    try:
        with urllib.request.urlopen(req, timeout=TIMEOUT, context=ssl.create_default_context()) as r:
            raw = r.read()
            charset = r.headers.get_content_charset() or "utf-8"
    except urllib.error.HTTPError as e:
        raise StopRun(f"Сайт {url} ответил ошибкой {e.code}. Проверьте адрес или попробуйте позже.")
    except (urllib.error.URLError, TimeoutError, OSError) as e:
        why = e.reason if hasattr(e, "reason") else e
        if "CERTIFICATE" in str(why).upper():
            raise StopRun(f"Сайт {url}: сеть компании подменяет сертификат. Передайте ИТ, что Python не доверяет сертификату прокси.")
        raise StopRun(f"Сайт {url} не ответил за {TIMEOUT} секунд. Проверьте интернет и запустите снова.")
    return raw.decode(charset, errors="replace")
```

Разбор ответа: таблицы и тексты страницы ищи `html.parser` или регулярными выражениями по видимым подписям (название сети, «АИ-92»), не по номеру строки страницы. JSON: `json.loads`. Каждое значение, которое не нашлось, это `None` и строка в «разобрать вручную» с адресом.
